SheetDecode

Read the formula you did not write

What is SheetDecode?

Paste a spreadsheet formula and SheetDecode breaks it into the order it runs in, names what each argument is for, warns about the mistakes that formula shape is prone to, and diagnoses the red error values.

What it does

  • Read any formula — SheetDecode explains which range is being searched, which is being added, and which value is the fallback. Nested functions become an indented outline instead of a wall of brackets.
  • Catch the traps — some mistakes never show an error and just return the wrong number: a lookup left on approximate match, criteria missing its quotation marks, or the two ranges of SUMIF in the wrong order. SheetDecode flags the traps a formula's shape is prone to.
  • Fix the red errors — #REF!, #VALUE!, #N/A, #DIV/0!, #NAME?, #NUM!, #NULL! and #SPILL! are each explained in plain language, with the causes worth checking first and the fix for every cause. When a formula is loaded, the errors it tends to produce are shown first.
  • Function reference — nearly fifty functions, described for someone reading a formula rather than writing one: what it does, what each argument means, and the one thing people get wrong about it.

How to use it

  1. Copy the formula from the cell you want to understand.
  2. Paste it into SheetDecode.
  3. Read the step-by-step breakdown, check any trap warnings, and open the error guide if the cell shows a red error value.

Frequently asked questions

Does it work offline?

Yes. Formulas are parsed on your device; nothing is uploaded.

Do you save the formulas I paste?

No. Formulas you decode stay in memory on your device for the length of your session. We do not save them, sync them, or send them anywhere, and there is no account or sign-in.

Which functions does it know?

Around fifty of the most common ones. A formula containing a function outside that set still gets its structure explained, and the unknown name is flagged — which is usually the cause of #NAME?.

Which error values can it explain?

#REF!, #VALUE!, #N/A, #DIV/0!, #NAME?, #NUM!, #NULL! and #SPILL!.

Why does it flag a formula that works?

Some warnings are about mistakes that produce a wrong answer rather than an error — an approximate-match lookup, for instance. They are worth reading even when the sheet looks fine.
